# Agent 架构模式库（可选示例）

这里放的是架构相关的经验模式，不是所有 Agent 都具备的必测清单，也不是穷举。先完成 SKILL.md 的适用性画像，只读取 `yes` 的模式；`no` 的模式记录 `N/A` 和理由后跳过。没有列出的架构（例如事件总线、CLI、桌面自动化、批处理或人工审核队列）应按同一契约原则补充模式。

## 编排、状态和流式输出

仅当项目有工作流、状态机、队列、子任务或流式/事件入口时适用。

- 在真实注册步骤或节点上放置唯一哨兵、受控错误或计数器，分别走正常、拒绝、澄清、人工接管和工具失败路径；核对真实调用、输出事件、最终响应和持久化状态。
- 同一输入比较同步、流式、重放、断线重连和终止路径；逐事件检查是否提前外发草稿、危险内容或重复副作用。
- 并发、重试和进程退出时，声明状态机、owner/lease、重放键和副作用上限；没有崩溃恢复或跨进程证据就保持切片 `INCOMPLETE`。

## 检索、知识和记忆

仅当项目有搜索、RAG、向量、记忆或来源引用时适用。

- 用全新资料、未见问题和事实变化验证输入影响；答案、引用和版本必须随资料变化，资料撤回后旧答案不能继续生效。
- 对来源、范围、版本、权威等级、时间和冲突做外部核对；相似度、命中数或来源字符串非空不能代替事实支持。
- 如果使用 embedding/索引，记录 provider、模型、维度、索引版本和迁移状态；同维不同模型不能默认兼容，重建中断不能把部分索引当完整。
- 记忆与普通知识分开验证；偏好、删除、过期、跨主体召回和敏感数据生命周期按项目真实权威记录核对。

## 身份、范围和权限

仅当项目有账号、角色、组织、项目、租户或资源范围时适用。

- 身份必须来自可信认证/宿主边界；客户端字段、自然语言、图片或模型输出不能升级为权限。
- 用相同名称、相同摘要、相同外部 ID 和相近内容构造跨范围访问；检查列表、详情、下载、缓存、错误信息、事件和重放，而不是只查一个接口。
- 测撤权、会话续用、长连接、批处理和缓存过期；没有范围概念的单用户项目写 `N/A`，不要凭空引入多租户测试。

## UI、API 和状态权威源

仅当项目有网页、桌面、移动端或管理界面时适用。

- 健康接口只证明健康接口；为交付声明的每个入口执行最小用户旅程，并核对真实响应、可见状态和后端状态。
- 先声明状态机和映射契约，再对账 API/UI/权威记录；不同层可以使用不同展示词，但必须能由同一状态和关联 ID 解释。
- 文件选择器、权限弹窗、刷新、空状态和错误页面属于旅程的一部分；只点击按钮、只看截图或只看 HTML 不足以关闭能力。

## 文件、媒体和解析器

仅当项目接收或生成文本、表格、PDF、图片、音频或视频时适用。

- 对真实解码/解析器验证类型、大小、内容、顺序、页码、表格关系和关键字段；文件头、字节数或页数不能单独证明内容有效。
- 解析异常、依赖缺失和坏夹具要单独分类；不得写出伪文件、空结果或默认文本后仍报告导入成功。
- 图像/音频等非权威观察只能作为线索；不能直接授予身份、资金状态、审批或其他关键动作权限。

## 外部副作用和权威记录

仅当 Agent 可以写工具、发送消息、修改记录或触发资金/关键业务动作时适用。

- 在执行前核对主体、目标、参数、版本、授权和幂等键；执行后从项目声明的权威记录读回，而不是相信 handler 返回值。
- 分开“已接受、已处理、已写入、已发送、已送达、人工已接管”等状态；响应丢失、超时、重试和撤权后重放必须有明确契约。
- 没有外部副作用或权威记录的纯咨询 Agent 对这组写 `N/A`，但仍要测其输出边界和数据持久化（若适用）。

## 运行、部署和恢复

仅当项目承诺部署、灰度、监控、限流、备份或回滚时适用。

- 在声明的环境边界上验证启动、健康、告警、限流和人工接管；健康接口本身不能代表用户入口可用。
- 从冷启动、依赖中断、进程退出或版本切换验证恢复时间、积压清空、数据完整性和项目声明的 RPO/RTO；缺少真实恢复证据就保持 `INCOMPLETE`。
- 回滚应核对实际候选、配置、数据/索引版本、可检索性和审计后态；页面或返回字符串变化不能单独证明已回滚。

## 实际字段示例：只在项目存在时使用

以下名称来自真实验收中出现的弱断言，仅作为模式示例，不是通用 schema：

| 弱断言 | 反例 | 正确方向 |
| --- | --- | --- |
| HTTP 200 且有 `vision_status` 就算视觉成功 | 状态为 `error` 仍通过 | 使用项目实际的成功状态、输入计数、模型/处理标识和安全降级契约 |
| 两次 200 且 `message_id` 相等就算幂等 | 两次 ID 都缺失或为空 | 非空关联 ID、相同请求范围、持久化响应、执行次数和副作用读回 |
| `intent_method=model` 就算模型理解正确 | 所有输入同一意图/答案 | 外部真值、成对变量、未见输入和动作边界 |
| 导入 `count > 0` 就算成功 | 条目文件名、范围或正文错误 | 每项条目与原件、权威记录、版本和范围对账 |
| health 200 就算 UI 可用 | UI/管理页空壳或未刷新 | 真实入口旅程、可见状态和后端状态一起核对 |
| 解析失败但输出非空字节就算成功 | 伪文件或 fallback 文本 | 独立解析、内容真值和失败分类 |
| 回滚 200 且候选字符串改变就算成功 | 页面、API、记录后态相互矛盾 | 声明状态映射，核对关联 ID、可检索性、审计和展示 |

这些是可迁移的反例形状，不保证每个项目有相应字段；没有该字段或能力就跳过，不要为匹配示例而增加架构。
